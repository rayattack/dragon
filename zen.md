# The Zen of Dragon

Dragon is... the snake that became a Dragon
Here, the hot path is sacred
If interpreted it is, sacred it is not  --said **Yoda** *arguably*

Fast is better than slow, slow is better than broken
You should know if it is broken when you compile
Readability counts, and a block ends where you say it ends

If you are the only one that understands it, it is wrong
In the face of ambiguity, annotate
If it walks like a duck, declare it `Duck`

An error is feedback, not a verdict
A silent fallback is a silent lie
A workaround is a wound - fix the root cause

Nothing should ever be complex, but complex is better than nothing
There should be only one correct way to do it
Unless it is the fastest way, you haven't found it yet

Anything that can be done in Dragon must be done in Dragon
A scope that ends frees what it held
A knowable type is never boxed

Types are one honking great idea -- let's monomorphize more of those!
